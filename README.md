# Microsoft Entra IAM Portfolio

Hands-on Identity and Access Management portfolio demonstrating the design, implementation, and security of enterprise identity controls using Microsoft Entra ID.

## About This Portfolio

This repository documents a simulated enterprise IAM environment created to develop practical experience with Microsoft Entra ID.

The lab environment represents **ChimaHealth Systems**, a fictional healthcare technology organization.

The portfolio focuses on practical implementation of identity security concepts including:

* Identity administration
* Role-Based Access Control (RBAC)
* Least privilege
* Multi-Factor Authentication (MFA)
* Conditional Access
* Identity lifecycle management
* Single Sign-On (SSO)
* Identity Governance and Administration (IGA)
* Privileged access
* IAM automation
